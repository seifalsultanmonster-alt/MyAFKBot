# Aternos Safe Bot

A minimal Mineflayer connection monitor and status dashboard.

## Setup
1. Copy settings.example.json to settings.json.
2. Review the settings locally.
3. Run `npm install`.
4. Run `npm start`.

Never commit settings.json, passwords, Microsoft tokens, launcher account files, or .env files.

## Important
This does not guarantee 24/7 availability on Aternos. Aternos can stop free servers under its platform inactivity policy. Use an authorized host for truly continuous availability.
